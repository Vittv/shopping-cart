### Building
You can run this app locally by cloning the repo and installing itis dependencies:

```bash
git clone https://github.com/Vittv/shopping-cart.git
cd shopping-cart
npm install
```

Then you can open the local server with:

```bash
npm run dev
```

It should then be available at `http://localhost:5173`.
